# ADR-007: 「メンバー募集」フローティングの撤去とクラウドファンディングカードの追加

## ステータス

承認済み

## コンテキスト

2026-08-30 のホームページ改善方針会議（第1回）で、トップページに常駐するフローティング要素の見直しが議題となった。

- 「メンバー募集」ダイアログ（`#recruit-dialog`）は初回訪問時に全画面オーバーレイで表示され、**モバイルのファーストビューを覆い隠していた**。閉じても左下にバッジが常駐する。
- 選手募集はシーズン前の限られた時期にのみ意味があり、**通年で最前面に出す情報ではない**。
- 現在の優先事項はファン獲得・広報であり、スポチュニティで実施中のクラウドファンディングへの誘導を求められている（スポチュニティ側からの依頼）。

フローティング要素は同時に複数出すと互いに邪魔をするため、「募集」を下げて「クラファン」を上げる判断が必要になった。

## 決定

### 1. 「メンバー募集」フローティングを撤去する

- `docs/index.html` からダイアログ・バッジ・専用 `<style>` のマークアップと `<script src="./assets/recruit_banner/recruit-dialog.js">` を削除。
- `docs/assets/recruit_banner/`（`recruit-dialog.js`・`bg_raw.png`）も**ディレクトリごと削除**する。どこからも参照されない約2.6MBのアセットを GitHub Pages で配信し続けないため。
- 再開時はコミット `b5fedf6` の `docs/index.html`（マークアップ・script タグ）と `docs/assets/recruit_banner/` を git 履歴から復元する。

### 2. クラウドファンディング告知カードを追加する

- `docs/assets/crowdfunding/crowdfunding-banner.js` が設定ファイル `docs/assets/crowdfunding/index.json`（`url` / `title` / `description` / `thumbnail` / `endsAt`）を fetch し、画面**右下**に小カード（OGPサムネイル＋タイトル＋一言＋「支援する →」）を生成する。文言・リンク先の変更は JSON の編集だけで済む。
- ページ表示から 1.5 秒後にスライドインし、ファーストペイントと競合させない。
- 「×」で閉じるとそのセッション中は非表示（`sessionStorage`）。タブを閉じれば再表示される。
- `endsAt` を設定するとその日を過ぎて自動で消える。
- リンク先は当面 `https://www.spportunity.com/tokyo/team/1063/invest/810/detail`。**計測用リンクはスポチュニティから受領後に `index.json` の `url` を差し替える**（別タスク）。

## 理由

- ファーストビューを覆わない「右下の小カード」であれば、動画ヒーロー（ADR-008）の体験を損なわずに誘導できる。
- 全画面オーバーレイと違い、閉じる操作が 1 タップで済む。
- 募集は git 履歴（`b5fedf6`）から丸ごと戻せるため、未参照アセットを残しておく理由がない。シーズン前の再開コストは復元コミット 1 つ分。

## 代替案

### 代替案1: 募集とクラファンを両方フローティングで出す

- 利点: 情報を落とさない
- 欠点: 左下バッジ＋右下カードで画面下部が塞がり、モバイルでは致命的
- 不採用の理由: 優先度の低い募集を残す価値より、視認性の損失が大きい

### 代替案2: クラファンをヒーロー内のボタンやNEWSセクションで告知する

- 利点: 追加のフローティング要素が不要
- 欠点: スクロールすると見えなくなり、依頼元が求める「常時見える導線」にならない
- 不採用の理由: 期間限定施策のため、ページ構造を変えずに着脱できるフローティングが適切

### 代替案3: 募集ダイアログの表示条件を緩める（時間差表示など）

- 利点: 既存実装を活かせる
- 欠点: 表示されれば結局ファーストビューを覆う。根本解決にならない
- 不採用の理由: 「今は募集を出さない」という方針判断が先にある

## 結果

### 良い影響

- モバイルのファーストビューが動画ヒーローとして初めから見える
- クラファンへの導線がすべてのスクロール位置で確保される
- 期間終了後は `endsAt` だけで自然に消える

### 悪い影響

- 選手募集への導線がトップページから消える（問い合わせは CONTACT 経由に一本化）

### リスク

- 計測用リンクの差し替え漏れ → `index.json` の `url` に集約し、運用手順書に明記
- カードが SNS の共有シートなど OS の UI と重なる端末がある → `bottom-4 right-4` の余白で回避、問題が出たら調整

## 実装への影響

- 必要な作業: `docs/index.html`（募集マークアップ削除・script 差し替え）、`docs/assets/recruit_banner/` の削除、`docs/assets/crowdfunding/`（`index.json`・JS・サムネイル追加）
- 影響を受けるコンポーネント: トップページのフローティング UI のみ。他セクションへの影響なし
- 移行計画: 募集再開時は本ADRの「決定 1」の手順で復元
